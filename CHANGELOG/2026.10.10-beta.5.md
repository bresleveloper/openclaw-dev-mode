## 2026.10.10-beta.5

### Highlights

- Node compatibility: installs and updates work again on Node `>=24.16.0 <25 || >=26.1.0`; Node 24.22.1 or 26.12.1 is now a security recommendation instead of a hard requirement, and Node 26 workers no longer abort when stdin is a file. (#186589, #187516) Thanks @RomneyDa.
- Gateway streaming: replies that contain tool-call-like XML, look like tool calls, or end long HTML at a partial tag no longer stall the Gateway. (#181397, #183252, #180765; related #175156, #180720) Thanks @RomneyDa, @JasonBuildAI, and @LeizhenZhang.
- Updates and rollback: a failed npm rollback no longer strands the installed package, an immediate Git rollback keeps operator edits, and an update whose executor dies recovers its offline state. (#185160, #185201, #181695; related #184889, #184887, #181649) Thanks @LiuwqGit, @RomneyDa, @syxscott, @wr-web, and @PonySlayer28.
- Cron: missed slots with a stale stored next run time are no longer dropped, and startup catch-up runs are admitted after a restart. (#179928; related #179927) Thanks @andrewbowlds, @RomneyDa, and @shakkernerd.
